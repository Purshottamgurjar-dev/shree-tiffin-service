# Shree Tiffin Service — Owner Cloud Activation Runbook
### Tagline: *“Ghar Jaisa Khana, Har Din.”*

This step-by-step runbook provides the exact, streamlined actions for the account owner to take the fully verified codebase and launch it onto **GitHub**, **Render (Backend + Frontend)**, **MongoDB Atlas**, and **Razorpay**.

---

## Part A — Push Codebase to GitHub

Open PowerShell or Command Prompt in `c:\Users\abc\Desktop\Shree tiffin service`:

1. **Check if a remote is already configured**:
   ```bash
   git remote -v
   ```
2. **If no Git repository is initialized or no remote exists**:
   ```bash
   git init
   git add .
   git commit -m "Shree Tiffin Service: Production Release"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/shree-tiffin-service.git
   git push -u origin main
   ```
3. **If remote `origin` already exists and points to your repo**:
   ```bash
   git add .
   git commit -m "Shree Tiffin Service: Production Release"
   git push -u origin main
   ```

*(Note: Secrets and `.env` files are automatically ignored by `.gitignore` and will never be pushed).*

---

## Part B — One-Click Render Blueprint Deployment

1. Sign in to your [Render Dashboard](https://dashboard.render.com).
2. Click **New +** (top right) $\rightarrow$ select **Blueprint**.
3. Connect your GitHub account and select the `shree-tiffin-service` repository.
4. Render will automatically detect and parse [render.yaml](file:///c:/Users/abc/Desktop/Shree%20tiffin%20service/render.yaml):
   * **`shree-tiffin-api`**: Node.js Web Service (Backend API)
   * **`shree-tiffin`**: Static Site (React Single Page Application)
5. Click **Apply**.

---

## Part C — Production Environment Variables in Render

Populate your private environment variables in the Render Dashboard under **Environment**:

### 1. Backend Web Service (`shree-tiffin-api`)

| Variable Name | Required Value / Source | Description |
| :--- | :--- | :--- |
| `NODE_ENV` | `production` | Enables error sanitization & production security (pre-set in Blueprint) |
| `PORT` | `10000` | Dynamic port assigned by Render (pre-set in Blueprint) |
| `MONGO_URI` | `mongodb+srv://<user>:<password>@cluster.mongodb.net/shree_tiffin_service?retryWrites=true&w=majority` | Your live MongoDB Atlas production URI (target DB MUST be `shree_tiffin_service`) |
| `CLIENT_URL` | `https://shree-tiffin.onrender.com` | Your assigned Render frontend URL for strict CORS validation |
| `JWT_SECRET` | Auto-generated by Render (or 32+ random characters) | Cryptographic secret for signing auth tokens |
| `JWT_EXPIRE` | `30d` | JWT session lifetime |
| `RAZORPAY_KEY_ID` | `rzp_test_...` (or `rzp_live_...`) | Your Key ID from Razorpay Dashboard |
| `RAZORPAY_KEY_SECRET` | Secret key from Razorpay Dashboard | Private secret for server-side HMAC SHA-256 signature verification |
| `RAZORPAY_WEBHOOK_SECRET`| Webhook secret from Razorpay Dashboard | Secret for verifying webhook authenticity |
| `OWNER_EMAIL` | Client owner business email | Owner credentials are provisioned securely during deployment |
| `OWNER_PASSWORD` | Strong secure password (min 8 chars) | Owner credentials are provisioned securely during deployment |

> [!CAUTION]
> **Never share or paste production secrets into public chat or GitHub.** Enter them directly into the secure Render Dashboard.

### 2. Frontend Static Site (`shree-tiffin`)

| Variable Name | Required Value | Description |
| :--- | :--- | :--- |
| `VITE_API_BASE_URL` | `https://shree-tiffin-api.onrender.com/api` | Direct HTTPS URL to your backend Web Service |
| `VITE_RAZORPAY_KEY_ID` | `rzp_test_...` (or `rzp_live_...`) | Public Key ID only (*never put Key Secret here*) |

*(Note: The frontend code supports both `VITE_API_BASE_URL` and `VITE_API_URL` aliases).*

## Part D — Configure Razorpay Webhook

After Render deploys the backend and provides your live backend URL (e.g., `https://shree-tiffin-api.onrender.com`):

1. Log in to your [Razorpay Dashboard](https://dashboard.razorpay.com).
2. Go to **Settings** $\rightarrow$ **Webhooks** $\rightarrow$ **Add New Webhook**.
3. **Webhook URL**: `https://<YOUR-ACTUAL-BACKEND-URL>/api/payments/webhook`
4. **Secret**: Enter the exact string configured as `RAZORPAY_WEBHOOK_SECRET` in your Render backend.
5. **Active Events**:
   * `payment.captured`
   * `payment.failed`
   * `order.paid`
6. Click **Save Webhook**.

## Part E — Live Cloud Verification

Once both Render services show green checkmarks (**Live**):

1. **Verify Backend Health & DB Connectivity**:
   ```text
   GET https://<YOUR-ACTUAL-BACKEND-URL>/api/health
   GET https://<YOUR-ACTUAL-BACKEND-URL>/api/ready
   ```
   *Expectation*: HTTP 200 OK, `{"status": "online", "database": "connected", "ready": true}`.

2. **Verify Frontend Single Page Application**:
   * Open `https://<YOUR-ACTUAL-FRONTEND-URL>` in your browser.
   * Register a customer account and log in.
   * Browse dishes and add a Thali to cart.
   * Select delivery address on the interactive Leaflet map.
   * Place a test order (COD or Razorpay Test Mode).
   * Confirm the order appears with sequential number (`STS-2026-XXXX`).

3. **Verify Owner Admin Operations**:
   * Navigate to `https://<YOUR-ACTUAL-FRONTEND-URL>/admin/login`.
   * Log in using your `OWNER_EMAIL` and `OWNER_PASSWORD`.
   * Confirm orders appear in Admin Dashboard.
   * Test status transition: `Pending` $\rightarrow$ `Confirmed` $\rightarrow$ `Preparing` $\rightarrow$ `Out for Delivery` $\rightarrow$ `Delivered`.
   * Review Analytics dashboard and download business report CSV.
